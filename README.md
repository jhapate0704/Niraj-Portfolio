## ✨ Overview

A fully responsive, single-page portfolio website built with **vanilla HTML, CSS, and JavaScript** — no frameworks, no build tools, just clean front-end code. Features rich animations, glassmorphism-inspired styling, and an immersive user experience designed to leave a lasting impression.

## 📸 Sections

| Section | Description |

## 🚀 Getting Started

### Prerequisites
- A modern web browser (Chrome, Firefox, Edge, Safari)
- (Optional) A local server for development — e.g., [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) VS Code extension

### Run Locally

```bash
# Clone the repository
git clone https://github.com/jhapate0704/Niraj-Portfoliyo.git

# Navigate into the project
cd Niraj-Portfoliyo

# Open in browser (or use Live Server)
start index.html        # Windows
open index.html         # macOS
xdg-open index.html     # Linux
```

No build step required — it's pure HTML/CSS/JS!

## ✉️ Contact Form Setup

The contact form uses **EmailJS** for serverless email delivery. The credentials are already configured in [`script.js`](script.js). If you fork this project, replace the following with your own EmailJS keys:

```js
emailjs.init("YOUR_PUBLIC_KEY");
emailjs.sendForm("YOUR_SERVICE_ID", "YOUR_TEMPLATE_ID", form);
```
